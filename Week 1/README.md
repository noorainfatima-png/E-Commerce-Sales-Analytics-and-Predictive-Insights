# **WEEK 1 – Data Ingestion & Initial Setup**

---

### **Project**
E-Commerce Sales Analytics and Predictive Insights

### **Objective**
The goal of Week 1 is to establish the project repository structure, ingest the raw dataset, setup the environment, and perform initial checks to understand data schema, missing values, and structure.

### **Tools**
* Python
* Pandas
* Jupyter Notebook

---

### **Week 1 Overview**
This week focuses on project initialization and initial data assessment. Key tasks include configuring the repository structure, loading the raw dataset, inspecting column types and summary statistics, and identifying initial data quality issues to prepare for detailed cleaning in Week 2.
