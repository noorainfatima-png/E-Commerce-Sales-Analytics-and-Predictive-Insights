# **WEEK 2 – Data Collection & Cleaning Framework**

---

### **Project**
E-Commerce Sales Analytics and Predictive Insights

### **Objective**
The project aims to collect, inspect, clean, and validate historical transaction data from the UCI Online Retail Dataset, creating a high-quality, analysis-ready dataset for exploratory data analysis (EDA) and predictive modeling.

### **Tools**
* Python
* Pandas
* NumPy
* Jupyter Notebook

---

### **Week 2 Overview**
This week focuses on designing and implementing a business-aware data collection and cleaning framework. Key tasks include handling missing values (e.g., CustomerID, Description), removing duplicate records, correcting data types, creating derived features (such as Revenue), and investigating negative quantities, cancelled transactions, and numerical outliers without unnecessary data loss.
